## Kiwu para Android 0.3.2 · carpetas, eventos y Ajustes por secciones

Se instala encima de la 0.2.1 conservando los datos. La base de datos se actualiza sola a la versión 4 sin tocar lo que ya hay, y las copias `.kiwu.json` antiguas se siguen pudiendo importar.

### Novedades

- **Carpetas de listas:** agrupa tus listas en carpetas (un solo nivel). Crea una lista directamente dentro de una carpeta, arrastra una lista hasta una carpeta (o fuera de ella) con pulsación larga, y pon un emoji opcional al crear. Pliega y despliega cada carpeta; al tocar su nombre ves todas sus tareas juntas.
- **Eventos:** una lista fija «Eventos» para cosas que pasan y no se completan (cumpleaños, charlas). Sin círculo, aparecen en el Calendario, en «Hoy» y en «Próximos 7 días», y avisan 1 hora antes (los de todo el día, desde las 9:00). No cuentan como tareas pendientes.
- **La hora es opcional:** al elegir la fecha de una tarea, «Aceptar» deja solo el día y «Añadir hora» abre el selector de hora (con el interruptor «Todo el día»).
- **Ajustes por secciones:** una pantalla corta con Apariencia, Menú de Tareas, Avisos, Copia de seguridad y Acerca de, cada una con su resumen. El fondo de imagen está dentro de Apariencia. Los tres aspectos del menú de tareas se eligen viendo una vista previa.
- **Horario:** la hoja de tareas de cada clase, puntos de urgencia y un color a elegir por clase.

### Cambios

- El aspecto «Compacto» del menú de tareas solo hace las filas más bajas; los contadores los controla únicamente el interruptor «Mostrar el número de tareas».
- Las listas y carpetas ya no llevan color propio; el aspecto «Con color» usa su emoji o un punto de color.

### Limitaciones conocidas

- Sin sincronización entre dispositivos todavía; el tablero no se ofrece en teléfonos.
- Los eventos solo tienen hora de inicio (sin hora de fin ni repetición anual).
